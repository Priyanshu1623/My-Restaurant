# Zayka-Vibe - Premium Restaurant Landing Page 🍽️✨

**[🔴 Live Demo - Click Here]( https://priyanshu1623.github.io/My-Restaurant/)**
 
A modern and fully responsive landing page designed for fine-dining restaurants. This project features a sophisticated dark theme with gold accents and an interactive table reservation modal, perfect for showcasing front-end development skills.

## 🌟 Features
- **Premium Dark Theme:** Elegant UI with gold accents tailored for luxury dining.
- **Fully Responsive:** Seamlessly adapts to desktops, tablets, and mobile devices.
- **Interactive Reservation Modal:** A dual-step booking popup (Form entry ➡️ Success Confirmation).
- **Smooth Scrolling & Sticky Navbar:** Enhanced user experience with a modern, dynamic navigation bar.
- **CSS Filtered Dark Map:** Embedded Google Map customized with CSS filters to match the dark aesthetic.
- **Single File Architecture:** HTML, CSS, and JS combined into one optimized file for easy deployment.

## 🛠️ Tech Stack
- **HTML5:** Semantic structure and layout.
- **CSS3:** Flexbox, CSS Grid, Custom Variables, and Keyframe Animations.
- **Vanilla JavaScript:** DOM manipulation, form handling, and event listeners (No external libraries used).

## 🚀 How to Use / Run Locally
1. Clone this repository or download the ZIP file.
2. Extract the files to your local machine.
3. Simply double-click the `index.html` file to open it in any modern web browser.
*(No server or build tools required!)*
